# アカウントとワークスペース

アカウントがあると、AIでロジックモデルを生成し、保存し、共有できます。保存したロジックモデルは**ワークスペース**に置かれます。自分だけで使う個人用ワークスペースと、チームで共同作業するために作成する共有のワークスペースがあります。

## アカウントなしでできること

| ログインなしで使える | ログインが必要 |
|----------------------|----------------|
| エビデンスの閲覧と検索 | AIによるロジックモデルと測定レシピの生成 |
| キャンバスでの手作業によるロジックモデルの構築と編集 | ロジックモデルの保存、バージョン履歴の確認、共有 |
| 画像とJSONのエクスポート | ワークスペースと、ロジックモデルの一覧 |
| リンクで共有されたロジックモデルの閲覧 | メンバーとして共有されたロジックモデルの閲覧 |

## ログイン {#signing-in}

1. サイドバー下部の **ログイン** をクリックします。ログインしていない状態で **保存** や **ログインして生成** をクリックしたときも、同じダイアログが開きます。
2. ダイアログ内の確認チェックが完了するまで待ちます。完了するまでボタンは押せません。
3. **Google でログイン** または **GitHub でログイン** を選びます。

アカウント登録の手順は別にありません。初回のログインでアカウントが作成されます。ログイン後は元のページに戻り、未保存のキャンバスの下書きも残っています。

ログインすると、利用規約とプライバシーポリシーに同意したものとみなされます。どちらも、ダイアログとサイドバー下部のリンクから確認できます。

ログアウトするには、サイドバー下部のアカウントメニュー（アバターと名前）を開き、**ログアウト** を選びます。

:::warning ログアウトすると未保存の下書きは消えます
ログアウトすると、そのブラウザに残っているキャンバスの下書きが削除されます。残したい内容は先に保存してください。
:::

## ワークスペース

ワークスペースは、ロジックモデルの置き場所です。すべてのアカウントには、本人だけが使える**個人用ワークスペース**が最初から用意されています。ほかの人と作業するには、共有のワークスペースを作成してメンバーを招待します。

### ワークスペースを切り替える

サイドバー上部の**ワークスペース切り替え**に、選択中のワークスペースが表示されます。開くと、所属しているほかのワークスペースに切り替えられます。**ロジックモデル** の一覧も、新しく保存するロジックモデルの保存先も、選択中のワークスペースに従います。

### ワークスペースを作成する

1. ワークスペース切り替えを開き、**ワークスペースを作成** をクリックします。
2. 名前を入力して確定します。

作成した人が、そのワークスペースのオーナーになります。ワークスペースの数には1アカウントあたり10個の上限があり、上限に達すると新しく作成できません。

### ロール

| ロール | できること |
|--------|------------|
| **オーナー** | 管理者ができることすべてに加えて、オーナーのロールの付与と、ワークスペースの削除 |
| **管理者** | ワークスペース設定の変更、メンバーの招待と除名、ロールの変更、ワークスペース内のロジックモデルの削除 |
| **メンバー** | ワークスペースでのロジックモデルの作成と、共有されたロジックモデルの閲覧 |

ワークスペースのメンバーであるだけでは、その中のすべてのロジックモデルを見られるわけではありません。それぞれのロジックモデルを見られるのは、オーナーと、[共有](./saving-sharing#sharing)された人です。

### メンバーを招待する {#inviting-members}

招待できるのは共有のワークスペースです。個人用ワークスペースには招待できません。

1. サイドバーで **組織 → メンバー** を開きます。
2. 招待する人のメールアドレスを入力し、ロールを選んで **招待** をクリックします。
3. 保留中の招待の **リンクをコピー** をクリックし、リンクを自分で相手に送ります。MUSEから招待メールは送信されません。

招待された人は、リンクを開き、招待先のメールアドレスを使うアカウントでログインして、**参加する** をクリックします。保留中の招待には有効期限が表示され、**招待を取り消す** で取り下げられます。

### ロールの変更とメンバーの除名

**メンバー** ページでは、オーナーと管理者がメンバーのロールを変更したり、**除名** をクリックしたりできます。除名された人がワークスペース内で共有していたロジックモデルはオーナーに引き継がれ、共有していなかったものは本人の個人用ワークスペースに移ります。

### ワークスペースの設定

**組織 → 設定** では、オーナーと管理者がワークスペースの名前を変更し、非公開モードを切り替えられます。

#### 非公開モード {#private-mode}

**非公開モード** を有効にすると、そのワークスペースでは次の2つが変わります。

- AI生成のときに、外部論文検索が実行されなくなります。
- リンク共有が使えなくなり、ワークスペース内の既存の共有リンクはすべて無効になります。

ワークスペース内のロジックモデルを外に出したくない場合に使います。

### ワークスペースの退会と削除

どちらも **組織 → 設定** の **危険な操作** にあります。個人用ワークスペースには、どちらもありません。

- **ワークスペースを退会**：共有していたロジックモデルはオーナーに引き継がれ、それ以外は自分の個人用ワークスペースに移ります。自分が唯一のオーナーである場合は、先にほかの人をオーナーにしてください。
- **ワークスペースを削除**（オーナーのみ）：ワークスペースと、そのメンバー、中のロジックモデルがすべて削除されます。元に戻せません。

## アカウント

サイドバー下部のアカウントメニューを開き、**アカウント** を選びます。

- **プロフィール**：表示名を変更できます。メールアドレスとアバターはログインに使ったサービスから取得され、変更できません。
- **ログイン方法**：Google と GitHub がアカウントに連携済みかどうかが表示されます。

### アカウントを削除する

**アカウントを削除** は、アカウントページの **危険な操作** にあります。アカウントを削除すると、次のようになります。

- 個人用ワークスペースと、その中のロジックモデルが削除されます。
- チームのワークスペースで共有していたロジックモデルは、そのワークスペースのオーナーに引き継がれます。共有していなかったものは削除されます。
- ブラウザに残っているキャンバスの下書きが削除されます。

共有のワークスペースで自分が唯一のオーナーである場合は、アカウントを削除する前に、ほかのオーナーを追加するか、そのワークスペースを削除してください。ログインしてから時間が経っている場合は、削除の前にもう一度ログインするよう求められます。
