# キャンバス概要

キャンバスはMUSEの中心となる場所です。ロジックモデルを構築・可視化・改善するための対話型ワークスペースです。AIが生成したフレームワークから手動で作成したプログラムの経路まで、すべてがここでつながります。

:::tip アクセス方法
[musecanvas.app/canvas](https://musecanvas.app/canvas) にアクセスするか、サイドバーの **「キャンバス」** をクリックしてください。
:::

:::info 初回のツアー
編集できるキャンバスを初めて開くと、主な操作を順に案内するツアーが始まります。キャンバス上部の **ヘルプ（?）** アイコンから、いつでももう一度見られます。
:::

## Canvas / Recipe タブ

キャンバスビューは上部で2つのタブに分かれています。

- **Canvas** — ノードを構築・編集・接続する対話型のReact Flowワークスペース
- **Recipe** — [測定レシピ](./recipe) ビュー。レシピを生成すると、アウトプット／アウトカムカード上の各メトリクスに対する実践者向け測定ガイドがここに表示されます

レシピが生成中の間はRecipeタブに小さなドットが表示され、レシピが *stale（古い内容）* — つまり生成後にロジックモデルが変更された — 状態のときは琥珀色の警告アイコンが表示されます。

タブの隣にはロジックモデルのタイトルが表示されます。保存済みのロジックモデルは、タイトルをクリックして名前を変更できます。

ヘッダー右側のツールバーには、選択中のタブに応じたアクションが表示されます。

![キャンバスビュー上部のキャンバス／レシピタブと、配置済みのロジックモデル。レシピタブには、レシピ生成後にロジックモデルが編集されたことを示す琥珀色のアイコンが表示されている。](/img/screenshots/ja/canvas-recipe-tabs.png)

## ツールバー

キャンバス上部にあるメインツールバーには、必要なすべての操作が揃っています。

| ボタン | 機能 |
|--------|------|
| **ロジックモデルを生成** | AI生成ダイアログを開きます。プログラムの内容を入力するとAIがロジックモデルを自動構築します（ログインが必要です） |
| **ノード追加** | 中央にノードエディタダイアログを開き、キャンバスに新しいノードを手動で追加できます |
| **保存** | ロジックモデルを、選択中のワークスペースに新しいバージョンとして保存します。ログインしていない場合は、ログインダイアログが開きます |
| **履歴**（時計アイコン） | 保存済みのロジックモデルのバージョン履歴を開きます |
| **共有**（共有アイコン） | 共有設定を開きます。保存済みのロジックモデルのオーナーにだけ表示されます |
| **ツアーを開始**（ヘルプアイコン） | 操作案内のツアーをもう一度表示します |
| **その他** | 追加アクションのドロップダウンメニューを表示します（詳細は下記） |

**レシピ** タブでは、先頭の2つがレシピ用のアクション（**レシピを生成**、**再生成**、**HTMLをダウンロード**）に置き換わります。保存、履歴、共有の詳細は[保存と共有](./saving-sharing)を参照してください。

### 「その他」ドロップダウンメニュー

**その他** をクリックすると、セクションごとに整理された以下のアクションにアクセスできます。

**キャンバス（Canvas）**

- **自動レイアウト（Auto Layout）** — ノードの配置を左→右のレイアウトに整え直します（AI生成の直後に実行されるのと同じ整列処理です）
- **画像エクスポート（Export Image）** — キャンバス全体のPNG画像をコピーまたはダウンロードします（外部共有時のトレーサビリティのために、「MUSE」のクレジットが入った枠が付きます）
- **JSONエクスポート（Export JSON）** — ロジックモデルのデータをファイルとしてダウンロードします

**レシピ（Recipe）**

- **再生成（Regenerate）** — 現在のメトリクスに対して [測定レシピ](./recipe) エージェントを再実行します
- **HTMLをダウンロード（Download HTML）** — 現在のレシピを自己完結型のHTMLファイルとしてダウンロードします（レシピが正常に生成されるまで無効です）

**危険な操作（Danger）**

- **すべてクリア（Clear All）** — キャンバス上のすべてを削除して最初からやり直します

閲覧のみの権限で開いたロジックモデルでは、**自動レイアウト** と **すべてクリア** は表示されません。生成、ノード追加、保存の各ボタンも同様です。

## 5種類のノード

ロジックモデルは5種類のノードで構成されており、それぞれがプログラムの因果関係における異なる段階を表しています。多くのタイプには固有の色が付いています。短期アウトカムと中期アウトカムは同じ黄色を共有するため、この2つはカードに表示されるタイプ名で見分けてください。

| ノードの種類 | 色 | 表すもの | 例 |
|--------------|-----|----------|-----|
| **アクティビティ** | 青 | プログラムが実施する具体的な活動 | 研修ワークショップの開催 |
| **アウトプット** | 緑 | 活動から生まれる直接的・測定可能な成果 | 200人の参加者が研修を修了 |
| **短期アウトカム** | 黄 | 知識・スキル・行動の初期変化 | デジタルリテラシーの向上 |
| **中期アウトカム** | 黄 | 目標に向けた中期的な変化 | 就職率の上昇 |
| **インパクト** | 紫 | 目指している長期的な社会変化 | 経済的格差の縮小 |

:::info ロジックモデルの読み方
左から右へ読みます。アクティビティがアウトプットにつながり、アウトプットが短期アウトカムに、短期アウトカムが中期アウトカムに、中期アウトカムがインパクトにつながります。各矢印は「これが次を引き起こす」という意味を持ちます。各矢印にエビデンスを添付するほど、モデルの信頼性が高まります。
:::

## エッジ（矢印）

キャンバス上の矢印はノード間の**因果関係**、つまり「ある段階が次の段階につながる」という主張を表しています。

- **通常の矢印（グレー／白）** — モデル内で主張している因果関係
- **緑の矢印** — 研究エビデンスによって裏付けられた因果関係

緑の矢印が表示されている場合、その因果関係のステップを裏付ける研究エビデンスが存在することを意味します。緑の矢印をクリックすると、リンクされたエビデンスを表示するダイアログが開きます。生成時に外部論文検索を有効にしていた場合、キュレーション済みエビデンスに加えてSemantic Scholarからの学術論文が参考資料として表示されることもあります。

![緑の矢印から開いたエビデンスダイアログ。2つのノードをつなぐ因果関係を裏付ける、リンク済みの研究エビデンスが一覧表示されている。](/img/screenshots/ja/evidence-dialog.png)

これはMUSEの最も強力な機能の一つであり、仮定をエビデンスに基づいた主張へと変えることができます。

## キャンバスの操作

キャンバスは無限に広がるパン可能なワークスペースです。移動方法は以下のとおりです。

| 操作 | 方法 |
|------|------|
| **パン（移動）** | キャンバスの空白部分をクリックしてドラッグする |
| **ズームイン** | マウスホイールを上にスクロール、またはズームコントロールの **+** ボタンをクリック |
| **ズームアウト** | マウスホイールを下にスクロール、またはズームコントロールの **-** ボタンをクリック |
| **全体表示** | ズームコントロールの全体表示ボタンをクリックしてモデル全体を確認 |
| **ミニマップ** | 隅にある小さなマップで概要を確認し、クリックして移動 |

## ノードの操作

キャンバス上にノードを配置した後、さまざまな方法で操作できます。

| 操作 | 方法 |
|------|------|
| **ノードを選択** | 一度クリックする — 選択枠が表示されてハイライトされます |
| **ノードを編集** | ダブルクリック、またはホバーして表示される鉛筆アイコンをクリック — どちらも中央のノードエディタダイアログを開きます |
| **ノードを移動** | クリックしてドラッグし、新しい位置に移動する |
| **ノードを削除** | 選択してから **Delete** キーまたは **Backspace** キーを押す |
| **2つのノードを接続** | 一方のノードの右端にある小さな点（ハンドル）から、もう一方のノードの左端のハンドルへドラッグする |
| **矢印を削除** | 矢印をクリックして選択し、**Delete** または **Backspace** キーを押す |

:::tip ノードの接続方法
ノードをホバーすると、端に小さな接続ハンドル（点）が表示されます。一方のハンドルから別のノードのハンドルへドラッグすると、因果関係を示す矢印が描かれます。
:::

## ミニマップ

キャンバスの隅には、ロジックモデルの全体像を示す小さなミニマップが表示されます。ミニマップでは以下の操作が可能です。

- **クリック** — ミニマップ上の任意の場所をクリックして、そのキャンバス部分に移動
- **ドラッグ** — ミニマップ内をドラッグして表示範囲を移動

ロジックモデルが大きくなり、異なるセクション間をすばやく移動したいときに特に便利です。

## 下書きと保存

作業中のキャンバスは、未保存の**下書き**としてブラウザに保持されます。ページを再読み込みしたりタブを閉じたりしても、編集内容は失われません。下書きはそのブラウザの中にだけあり、ログアウトすると削除されます。

ロジックモデルを残すには **保存** をクリックします。保存したロジックモデルはワークスペースに置かれ、サイドバーの **ロジックモデル** に一覧表示され、ログインすればどのデバイスからでも開けます。詳細は[保存と共有](./saving-sharing)を参照してください。
