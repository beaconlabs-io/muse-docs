# 測定レシピ

**測定レシピ（Measurement Recipe）** は、ロジックモデル上の抽象的なメトリクスを、プログラム運営者が実際に実行できる測定手順へと変換したものです。基本的なツール（スプレッドシート、短いアンケート、参加者名簿、フォローアップメッセージ）だけで実行できるように設計されています。

MUSEはインパクトプランニングを2段階に分けています。

1. **ロジックモデル** — 因果経路の軽量なアウトライン。各アウトプット／アウトカムカードのメトリクスは**名前**と短い**説明**のみを持ちます。
2. **レシピ** — その名前と説明、そして親カードの文脈から生成される実践ガイド。測定手順・データ収集方法・頻度・目標値・注意点はすべてこちらで扱います。

この分離により、モデルは軽くスケッチしながら、測定設計の作業はM&E初心者向けにチューニングされた専用エージェントに委ねることができます。

:::info レシピは誰に向けて書かれるか
レシピエージェントは、読み手がM&E（モニタリング＆評価）の初心者であり、基本的なツールしか使えないという前提で指示されています。メトリクスが明示的に要求しない限り、厳密な評価設計（統制群、検証済みスケール、複雑なサンプリング）は求めません。生成された内容は、そのままプログラム運営者に手渡せることを想定しています。
:::

## 前提条件

レシピを生成するには、キャンバスに以下が必要です。

- **アウトプット**、**短期アウトカム**、または **中期アウトカム** カードが1つ以上あること。  
  *（アクティビティやインパクトカードは、運用上の測定レイヤーの外にあるため、レシピの対象外です。）*
- 上記いずれかのカードにメトリクスが1つ以上添付されていること（名前は必須、説明は任意）。

いずれかの前提条件が満たされていない場合、レシピタブには「メトリクスがありません」または「対象カードがありません」というメッセージが、追加すべき内容の案内とともに表示されます。

## レシピの生成方法

レシピ生成をトリガーする方法は2つあります。

### 方法1 — 生成時にレシピを有効化する

[AI生成](./ai-generation)を使う場合、ロジックモデル生成ダイアログに **「測定レシピも生成」** トグルがあります。生成ボタンを押す前にこれを有効にすると、MUSEはロジックモデルとレシピを1回のストリーミング実行で同時に生成します。

ゼロから始めるときには、この方法を推奨します。AIがメトリクスとレシピを同じセッション内で一貫して生成します。

### 方法2 — 既存のキャンバスから生成する

すでにキャンバス上にロジックモデルがある場合（レシピトグルをオフにしてAI生成したもの、または手動で構築したもの）：

1. キャンバスビュー上部の **Recipe（レシピ）** タブをクリックする（**Canvas** タブの隣）。
2. レシピパネルが開きます。このキャンバスに対してレシピが一度も生成されていない場合、対象となるメトリクスの数が表示されたアイドル画面が現れます。
3. **Generate recipe（レシピを生成）** をクリックして、現在のメトリクスに対してレシピエージェントを実行します。

既存のレシピは、**More** メニュー → **Regenerate（再生成）** からいつでも再生成できます。

## レシピの内容

レシピは親カードの種類ごと — **アウトプット** → **短期アウトカム** → **中期アウトカム** の順 — に整理され、各メトリクスに対して以下のブロックが生成されます。

![レシピビュー。MUSE レシピのタイトル、「ロジックモデルが変更されました」というStaleバナー、アウトプットセクション、そして目標値・測定手順・データ収集方法・注意点を含むメトリクスカードが表示されている。](/img/screenshots/ja/recipe-view.png)

| 項目 | 内容 |
|------|------|
| **メトリクス名** | ロジックモデルからそのままコピーされます |
| **From（出典）** | メトリクスが属する親カードのタイトル |
| **目標値** *(任意)* | ベースラインとの比較で合理的な場合の目標（例：「ベースラインから10%改善」）。合理的なデフォルトがない場合は省略されます |
| **測定手順** | 実際に測定を実施するための具体的なアクションを、動詞で始まる命令形で3〜6ステップの順序付きリストで提示 |
| **データ収集方法** | データがどのように集められるかを1段落で説明（アンケート、行政記録、観察、Web解析など） |
| **頻度** | 推奨される測定サイクル（例：*月次*、*四半期*、*コホートごと*） |
| **注意点** | このメトリクス固有のバイアス・倫理的問題・データ品質リスクなど、1〜3件の実践的な留意点 |

:::tip 意図をレシピに反映させる
メトリクスを書くときは、そのメトリクスが何を捉えようとしているのかを短い説明として添えてください。レシピエージェントはこの説明を測定手順生成の主要なヒントとして使うため、名前だけを与えたときよりも鋭く、文脈に即した手順が得られます。
:::

## 言語の扱い

レシピはロジックモデルを書いた言語と同じ言語で生成されます。メトリクスやカードタイトルが日本語であればレシピも日本語で、英語であればレシピも英語で出力されます。エージェントは翻訳を行わず、作業言語をそのまま最後まで維持します。

## 「Stale（古い内容）」バッジ

レシピを生成した後にロジックモデルを編集すると、レシピタブに小さな琥珀色の警告アイコンが表示され、レシピビューには **「ロジックモデルが変更されました」** というバナーが出ます。

Staleは、表示中のレシピが以前のバージョンのキャンバスに対して生成されたものであることを示すだけです。内容は引き続き閲覧可能ですが、Moreメニューから **Regenerate** をクリックすれば、現在のキャンバスに合わせて更新できます。

## HTMLとしてダウンロード

レシピの生成が成功したら、自己完結型のHTMLファイルとしてプログラム運営者に手渡すことができます。

1. キャンバスツールバーの **More** メニューを開く
2. **Recipe** セクションの **Download HTML（HTMLをダウンロード）** をクリック
3. 単一の `.html` ファイルがブラウザのダウンロードフォルダーに保存されます

このファイルは自己完結型で、外部アセットを必要としません。そのままメール添付・メッセージング共有・アーカイブに利用できます。

:::info Download HTMLが無効な場合
レシピがまだ生成されていない場合（または前回の生成が失敗した場合）、**Download HTML** メニュー項目は無効になっています。先にレシピを生成してから、Moreメニューに戻ってください。
:::

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| レシピタブに「メトリクスがありません」と表示される | アウトプットまたはアウトカムカードにメトリクスを追加してください。[手動編集 → メトリクスの追加](./manual-editing#メトリクスをノードに追加する) を参照 |
| レシピタブに「ロジックモデルがまだありません」と表示される | 先にCanvasタブでロジックモデルを生成または構築してください |
| レシピタブに琥珀色のStaleバッジが表示される | 前回のレシピ生成後にロジックモデルが変更されました。Moreメニューから **Regenerate** をクリックしてください |
| 「Recipe generation failed」エラー | パネルから再試行してください。エラーが続く場合は、メトリクスの説明を簡素化するか、メトリクス数を減らしてから再試行してください |
| Download HTMLがグレーアウトしている | レシピがまだ生成されていない、または前回の実行に失敗しています。先に生成してください |
