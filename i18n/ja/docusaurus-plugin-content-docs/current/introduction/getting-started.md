# はじめに

MUSEへようこそ — [Beacon Labs](https://beaconlabs.io) が開発した、エビデンスに基づくインパクト計画ツールです。MUSEを使うと、研究エビデンスに裏付けられたロジックモデルを作成できます。

## MUSEとは？

MUSE（Modular Stack of Evidence）は、研究エビデンスと現実世界のインパクト計画との間にある隔たりを埋めます。MUSEでは以下のことができます：

- **ビジュアルなロジックモデルの作成**：プログラムのアクティビティが測定可能なインパクトにどうつながるかをマッピングする
- **AIの活用**：取り組みの説明を入力するだけで、ロジックモデルを自動生成する
- **研究エビデンスのリンク**：研究を、ロジックモデルの各ステップに関連付ける
- **保存、バージョン管理、共有**：ロジックモデルをワークスペースに保存し、過去のバージョンを復元し、チームのメンバーやリンクで共有する

## MUSEは誰のためのもの？

MUSEは、インパクトの計画と評価に携わるすべての人に向けて設計されています：

- **NGO・非営利団体** — エビデンスに基づくプログラムの立案
- **研究者** — 研究成果を実践的な応用につなげる
- **インパクト投資家** — 研究的裏付けを持つプログラム設計の評価
- **政策立案者** — エビデンスに基づく意思決定
- **デジタル公共財コミュニティ** — インパクトの追跡と検証

## MUSEにアクセスする

MUSEは [https://musecanvas.app](https://musecanvas.app) で利用できます。

:::info 言語サポート
MUSEは**英語**と**日本語**に対応しています。サイドバー下部の言語切り替えから、いつでも変更できます。
:::

:::info アカウントが必要になる操作
エビデンスの閲覧と、キャンバスでの手作業によるロジックモデルの構築は、アカウントなしで利用できます。AIによる生成、ロジックモデルの保存、共有には、**Google または GitHub でのログイン**が必要です。詳しくは[アカウントとワークスペース](../user-guide/accounts-workspaces)を参照してください。
:::

## クイックスタート：最初の5分間

1. **アプリにアクセス** — [musecanvas.app](https://musecanvas.app)を開く
2. **ログイン** — サイドバー下部の「ログイン」をクリックし、Google または GitHub で続行する
3. **キャンバスに移動** — サイドバーの「キャンバス」をクリック
4. **AIで生成** — 「ロジックモデルを生成」ボタンをクリックし、取り組みの内容を入力する
   - 例：*「OSSのEthereumエコシステムへのインパクト」*
   - 例：*「都市コミュニティの食料不安の軽減」*
5. **ロジックモデルを確認** — 約1分後に以下が表示されます：
   - 各ステージを表す色分けされたカード（アクティビティ → アウトプット → アウトカム → インパクト）
   - ステージ間の因果関係を示す矢印
   - エビデンスに裏付けられた接続を示す緑色のエッジ
6. **エビデンスを確認** — 緑色のエッジをクリックすると、各接続を支持する研究エビデンスが表示される
7. **保存** — キャンバス上部の「保存」をクリックし、ロジックモデルをワークスペースに保存する

![キャンバスに表示された、生成済みのロジックモデル。色分けされたノードが左から右へ流れ、エビデンスに裏付けられた緑の矢印が2つのステージをつないでいる。](/img/screenshots/ja/canvas-with-evidence.png)

以上です！エビデンスに基づくロジックモデルが完成しました。
