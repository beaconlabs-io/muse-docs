## Project Overview

MUSE documentation site built with **Docusaurus 3.9.2** (React 19, TypeScript, Tailwind).
Deployed at **https://docs.muse.beaconlabs.io**.

## Development Commands

```bash
bun install                    # Install dependencies
bun start                      # Dev server with hot reload (default :3000)
bun run build                  # Production build (static site → build/)
bun run serve                  # Serve the production build locally
bun run typecheck              # tsc (type-only, no emit)
bun run clear                  # Clear the Docusaurus cache (.docusaurus/)
bun run write-translations     # Extract translatable strings into i18n/
```

## Structure

- `docs/` — Markdown/MDX documentation content (source of the sidebar)
- `sidebars.ts` — Sidebar structure (autogenerated or explicit)
- `docusaurus.config.ts` — Site config: URL, i18n, theme, plugins
- `src/` — Custom React components, pages, and CSS
- `static/` — Static assets served at site root (e.g., `static/img/foo.png` → `/img/foo.png`)
- `i18n/` — Locale overrides and translated content

## Internationalization

- Default locale: **`en`**; additional locale: **`ja`** (`docusaurus.config.ts` → `i18n`)
- Translated docs live under `i18n/ja/` (currently ~16 translated files); English is the source of truth
- After adding/editing docs, run `bun run write-translations` to sync translation stubs

## Gotchas

- **Missing local images fail the build.** Docusaurus 3.9.x *throws* (not warns) when a Markdown
  image references a nonexistent local file. `bun start` may tolerate it, but `bun run build`
  hard-fails — verify every `![...](./path)` / `<img src>` resolves before building.
- **Tailwind is wired via an inline plugin** in `docusaurus.config.ts` (a small `tailwindPlugin`
  that pushes `tailwindcss` into PostCSS) — there is no separate `@docusaurus/plugin-*` for it.
- Stale builds/hot-reload glitches: run `bun run clear` to drop the `.docusaurus/` cache.
